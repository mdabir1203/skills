# Changelog

All notable changes to this skill are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-02

### Added
- Initial release of the `keynote-explainer` skill
- 5-stage pipeline: brief → concept → storyboard → build → world-class review
- Three reference worlds: Apple (hero-shot minimalism), Google I/O (data-precise optimism), Silicon Valley editorial (cinematic dark)
- Six neuromarketing drivers baked into the storyboard stage: open loop, pattern interrupt, mystery gap, specificity, contrast, endowed progress
- 20 motion verbs in `references/motion-vocabulary.md`, with banned anti-verbs (bounce, flip in, rotate in, pulse, wobble)
- 12 ready color palettes in `references/color-palettes.md` across the 3 reference worlds
- Display + mono font pairings per tone in `references/typography-stack.md` (banned: Inter, Roboto, Open Sans, Lato)
- 20 controlled-imperfection moves in `references/imperfection-playbook.md` — the bold pass that signals "made by a person with taste"
- Remotion patterns in `references/remotion-patterns.md`: frame-driven motion, Sequence/Series, beat-synced audio, zod-typed props, the 5-stage verify loop (stills first, MP4 only after)
- Storyboard template with per-scene detail, gates, and anti-pattern sweep
- 9-pass world-class review checklist
- Minimum viable Remotion project scaffold
- PERSONALIZATION.md with 9 defaults (palette, fonts, tone, frame, length, brand name, tagline, music source)

### Notes
- v0.1.0 is the first public cut. Use it. Break it. Tell me what's missing. Bumping to 0.2.0 after the first batch of real briefs.
- The skill ships generic. Personalize via `PERSONALIZATION.md` (5 minutes).
