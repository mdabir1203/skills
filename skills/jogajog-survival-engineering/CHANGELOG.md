# Changelog

## [0.1.0] - 2026-09-05

### Added

- `SKILL.md` — entry point. Tri-cultural matrix (Russian axiom + Chinese velocity + Bangladeshi survival), 21 principles (4 phase + 4 meta + 4 anti-pattern + 9 cuts), how to apply, when NOT to use, reference index, composition with sister skills.
- `references/ground-truth-triage.md` — Phase 1. The discipline of diagnosing the actual failure point under pressure. Examples across software, electrical, civil, mechanical. The 5-step frame, tools by domain, anti-patterns (jumping to the most-available explanation, trusting the loudest report, triage fatigue, triage theatre).
- `references/frugal-improvisation.md` — Phase 2. The Jogar discipline. The 3 properties of a correct improvisation. The 6-step lifecycle (diagnose, improvise, document, monitor, promote or replace, audit). The 5 patterns (cache, queue, fallback, throttle, manual step). Anti-patterns (untracked, permanent, cargo-cult, layered, undocumented operator knowledge).
- `references/human-in-the-loop-safeguards.md` — Phase 3. The 4-component pattern (proposal, review, override, audit). When HITL is appropriate (safety-critical, high-value, irreversible, ambiguous, regulatory) vs not (high-volume, latency-critical, calibrated). The 5 anti-patterns (rubber-stamping, override theatre, late HITL, missing context, HITL as bug fix). The HITL + automation balance. Concrete patterns in software, industrial control, medical, aviation.
- `references/community-driven-hardening.md` — Phase 4. Community as a load-bearing system component. The reciprocity discipline. The 5 community structures (public forum, chat room, issue tracker, working group, meetup). The 5-step process (open the surface, triage, investigate, recognize, close the loop). Cross-domain examples (engineering, medical, public services). Anti-patterns (graveyard forum, exclusive circle, free consulting extraction, hostile moderation, contributor burnout).
- `references/beyond-software.md` — Cross-domain meta. The unifying lens (hostile substrate + resource constraint + human-in-the-loop necessity). Application to civil, mechanical, electrical, systems engineering, and public services. The cross-domain discipline.
